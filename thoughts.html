Supabase 云同步配置

配置后随笔数据将同步到云端，可在多设备间共享。不配置则继续使用本地存储。

需要先在 Supabase 创建 thoughts 表：
CREATE TABLE thoughts (id TEXT PRIMARY KEY, title TEXT, content TEXT, timestamp BIGINT);
Row Level Security: ALTER TABLE thoughts ENABLE ROW LEVEL SECURITY;
Policy: CREATE POLICY "anon_all" ON thoughts FOR ALL USING (true) WITH CHECK (true);

随想录 — 记录你的所思所想

部署到互联网（三选一）：
GitHub Pages：将 thoughts.html 上传到 GitHub 仓库，Settings → Pages → 选择分支 → Save。
Vercel：在 vercel.com 导入 GitHub 仓库，自动部署，支持自定义域名。
Netlify：拖拽 thoughts.html 到 app.netlify.com 的部署区域即可。
